# 🧠 Quiz de Programação em Python

Um jogo interativo de perguntas e respostas desenvolvido em Python para testar conhecimentos básicos de programação de forma divertida e prática.

## 🚀 Tecnologias Utilizadas

- **Python 3**
- **Estruturas de dados:** Listas e Dicionários
- **Controle de fluxo:** Laços de repetição (`for`) e condicionais (`if/else`)

## 📌 Funcionalidades

- Exibição dinâmica de perguntas de múltipla escolha.
- Tratamento de entrada do usuário (aceita letras maiúsculas/minúsculas e remove espaços extras).
- Sistema de pontuação em tempo real.
- Mensagem de feedback final baseada no desempenho do jogador.

## 🛠️ Como Executar o Projeto

1. Certifique-se de ter o [Python instalado](https://www.python.org/) no seu computador.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute o comando:
   ```bash
   python quiz.py
